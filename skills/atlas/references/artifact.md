# Standalone learning artifacts

Use this reference when a standalone HTML lesson is requested or clearly appropriate. A chat clarification does not need a file.

Build around the person's question and intended use. Lead with enough substance to establish the problem, then develop the explanation. Use headings that name the actual content. Do not require a fixed number of sections, an origin story, or a dramatic ending. End when the question has been answered; a compact reference or recap is appropriate when useful.

Use one self-contained HTML file with inline CSS and, if necessary, inline JavaScript. Avoid network dependencies so the core lesson works offline. Use semantic headings, readable line lengths, accessible contrast, responsive layout, and labeled controls. Support keyboard navigation and reduced motion. Keep main content available without JavaScript. Print should include exercise answers and source URLs.

Use explanatory SVG diagrams when they carry relationships better than prose. Supply a text explanation. For predictions, use a native details/summary element with an answer and explanation. For a simulation, show assumptions and units, handle boundary inputs, and explain what changing the control demonstrates. Prefer one useful interaction over several decorative ones.

Do not imitate a landing page. Keep body text in a continuous reading column; use a wider area only for a figure or comparison that benefits from it. Choose appearance for readability and the content, not a list of prohibited colors or fonts.

Place source links near the supported claims. A source list may supplement them for an investigation. Cite only real evidence; generated diagrams and simulations are explanatory models, not sources.

Open the finished page in an available browser. Check desktop and narrow widths, keyboard operation, answer reveals, console errors, and relevant simulation boundaries. Verify that the substantive content works without external assets. Correct problems before delivery. If visual inspection is unavailable, state that limit instead of claiming it passed.

Return the file link and a brief description of the question it answers. Do not infer that producing the artifact means the person learned the material.
