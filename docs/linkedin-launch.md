# LinkedIn launch draft

---

I built Atlas, a platform for learning through questions.

You start with something you want to understand. Ask follow-up questions, work
through examples, or take a detour into a prerequisite. You choose how far to go.

Explanations can include diagrams, interactive plots, and simulations. You can
save useful explanations to a library, and a concept graph shows how the ideas
you explored connect. Your conversations stay there when you want to return.

I wanted a place where learning could build over time, with useful explanations
and connections I could come back to.

A few things Atlas offers:

- 300 free credits for everyone, shared across conversations.
- Powered by Gemini 4 Argon.
- A knowledge graph aware agent that connects new ideas to concepts you've already explored.
- Generated images to help explain concepts visually.
- An interactive interface with inline diagrams, worked examples, comparisons, plots, and other learning artifacts.

This is an early version. If you try it, I'd like to hear what helped and where
the explanation fell short.
